# 17. Project instructions

**Classification:** Mandatory

## Required behavior
Keep AGENTS.md as the always-on root policy and load this skill for coding tasks. Preserve existing local instructions, specialist skills and explicit migration rules. Resolve conflicting technical guidance by inspecting source and documenting conflicts.

## Prohibited behavior and exceptions
Do not replace existing AGENTS.md, create competing policy or treat examples as authorization for production changes.

## Examples
Good: append a concise link and retain existing Onion/CQRS requirements; bad: replace specialist standards with a generic prompt.

## Review checklist
- [ ] Check policy links, nested instructions, scope, language and precedence.
- [ ] Record relevant evidence and justified deviations; do not claim an unexecuted check.

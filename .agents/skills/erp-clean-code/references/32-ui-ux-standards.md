# 32. UI/UX standards

**Classification:** Mandatory

## Required behavior
Load existing design-system, compact-form, responsive, typography, mobile-density and frontend reusable skills for applicable changes. Preserve RTL, theme tokens, button placement conventions, accessible labels, focus, keyboard, contrast, feedback and touch targets. Keep UI consistent and compact.

## Prohibited behavior and exceptions
No unrelated global restyling, duplicate modal/component, inaccessible icon-only controls or color-only status. Existing specialist constraints take precedence over examples.

## Examples
Good: shared filter modal with accessible label and loading state; bad: create a new inconsistent modal for the same filter.

## Review checklist
- [ ] Check desktop/mobile, RTL, keyboard, repeated use, state feedback and specialist references.
- [ ] Record relevant evidence and justified deviations; do not claim an unexecuted check.

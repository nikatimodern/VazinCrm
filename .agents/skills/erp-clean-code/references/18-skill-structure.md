# 18. Skill structure

**Classification:** Mandatory

## Required behavior
Use erp-clean-code/SKILL.md as a concise router with YAML name/description, numbered references and task-specific checklists. Keep detailed rules in references and specialist behavior in existing skills. Update links and checklist when changing policy.

## Prohibited behavior and exceptions
No redundant copies of specialist implementations, unsupported metadata or broken relative paths. Do not equate installation with automatic enforcement.

## Examples
Good: load the security reference for permission changes; bad: paste all rules into each feature folder.

## Review checklist
- [ ] Check 34 reference files, manifest, relative links, examples and discoverability.
- [ ] Record relevant evidence and justified deviations; do not claim an unexecuted check.

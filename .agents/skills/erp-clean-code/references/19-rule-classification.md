# 19. Rule classification

**Classification:** Mandatory

## Required behavior
Critical: security/data/financial safety, no bypass. Mandatory: comply or obtain documented authorized exception. Recommended: weigh tradeoffs and report material deviations. Optional: use when beneficial. Record rule, reason, scope, risk, approval and expiry for exceptions.

## Prohibited behavior and exceptions
No self-authorized exceptions to Critical rules, no style metrics classified as security gates, no silent waiver.

## Examples
Good: document framework-required signature exception; bad: bypass Scope for convenience.

## Review checklist
- [ ] Check severity, actual enforcement, exception record and absence of conflicts.
- [ ] Record relevant evidence and justified deviations; do not claim an unexecuted check.
